# Editorial quality release note

The initial LiquidityPool library used short explanatory drafts. This release replaces all 20 guides with **source-led long-form articles** built around concrete market situations, mechanism-first explanations, citations, counterexamples, reader decision questions, and internal links to adjacent concepts.

| Metric | Release result |
| --- | ---: |
| Guides rewritten | 20 |
| Article-body words including references | 45,674 |
| Average words per guide | 2,283 |
| Licensed internal editorial visuals | 20 |
| Article-level sources | 4–5 per guide |
| Standard reader safeguard | Educational content; no investment advice or performance forecasts |

Every guide includes a references section and its own image attribution. Source claims should be reviewed whenever a protocol makes material product or documentation changes.

---

## Keyword-research expansion release

A keyword research review of the site recommended building five mutually supporting content assets rather than competing for a single head term. This release implements that plan.

| Metric | Release result |
| --- | ---: |
| Guides in the library | 36 (24 existing, 12 new) |
| Article-body words | 73,003 |
| Internal guide links | 201 |
| Source definitions | 207 |
| Guides carrying an FAQ block and FAQPage data | 36 |
| Interactive calculators | 2 |

New guides target the highest-priority gaps identified in the research: out-of-range liquidity, the impermanent loss formula, fees versus impermanent loss, loss-versus-rebalancing, Uniswap v3 against v4, slippage and price impact, fee tiers, APR against APY, yield farming, pool types, pools against staking, and the ways a pooled position loses money. Figures for these guides are generated by `scripts/generate-guide-figures.py`.

## Full keyword coverage release

A line-by-line re-check of the keyword research against the site identified 51 keyword strings with no matching page. This release closes all of them and adds mechanical enforcement of the research's editorial rules.

| Metric | Release result |
| --- | ---: |
| Guides in the library | 55 |
| Article-body words | 100,090 |
| Internal guide links | 315 |
| Source definitions | 286 |
| FAQ entries in guides | 235 |
| Interactive calculators | 3 |
| Research keywords resolving to a page | 189 of 189 |

`pnpm content:audit` now additionally fails a guide that lacks worked numbers, lacks a comparison table, carries fewer than three FAQ entries, or contains guaranteed-yield and best-pool style claims. Every figure is generated by `scripts/generate-guide-figures.py`.

## Citation release

Nineteen guides carried reference definitions that markdown never rendered, so their References section appeared empty on the published page. Every guide now renders a numbered source list, and the citation floor has been raised.

| Metric | Release result |
| --- | ---: |
| Guides with a rendered reference list | 55 of 55 |
| Cited sources | 438 |
| Peer-reviewed or preprint research citations | 155 |
| Standards body and public-sector citations | 93 |
| Minimum sources per guide | 6 |
| Tool pages carrying a sources section | 4 of 4 |

Source URLs were normalised to canonical hosts, one dead link was replaced, and `pnpm links:check` was added to verify that every cited source resolves from a machine with network access.
